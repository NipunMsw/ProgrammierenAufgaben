# Programmieraufgaben

Dieses Repository enthält meine Programmierübungen aus dem Unterricht an der **MSW Winterthur** im Rahmen meiner Ausbildung zum **Elektroniker EFZ**. Die Programme werden hauptsächlich in **C für AVR-Mikrocontroller** mit **Microchip Studio** entwickelt.

## Angaben

- **Name:** Nipun Golla
- **Klasse:** BFS-EK25
- **Ausbildung:** Elektroniker EFZ
- **Schule:** MSW Winterthur

## Inhalte

Die Übungen behandeln verschiedene Grundlagen der Mikrocontroller-Programmierung, darunter:

- **Digitale Ein- und Ausgänge:** Ports konfigurieren und LEDs, Taster sowie Schalter ansteuern oder auslesen.
- **Programmabläufe:** Bedingungen, Schleifen, Zähler und Zeitverzögerungen einsetzen.
- **Operatoren und Bitoperationen:** Werte vergleichen, logische Verknüpfungen verwenden und einzelne Bits gezielt bearbeiten.
- **Analoge Signale:** Messwerte über den Analog-Digital-Wandler (ADC) erfassen und im Programm verarbeiten.
- **Fehlersuche:** Programme testen, das Verhalten prüfen und Fehler im Code korrigieren.

## Aufbau des Repositories

Jede Übung befindet sich in einem eigenen, möglichst eindeutig benannten Ordner. Darin liegen der C-Quellcode und die zugehörigen Projektdateien. Nicht benötigte Build-Dateien und temporäre Dateien werden über `.gitignore` ausgeschlossen.

Änderungen werden mit Git dokumentiert und auf GitHub hochgeladen. Das Repository wird im Laufe der Ausbildung um weitere Übungen ergänzt.
